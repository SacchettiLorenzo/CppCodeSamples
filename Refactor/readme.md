# Repository Management Guide

# 1. Directory Structure Rules
The main directory must contain:
- Makefile
- readme.md file
- log direcotry (generated by makefile)
- bin direcotry (generated by makefile)

Every source file must be inserted in a directory
# 2. File Naming Conventions
All files must have a name with only lowercase letter and the spaces must be replaced with underscores
# 3. Directory Naming Conventions
All directories must have a name with only lowercase letter and the spaces must be replaced with underscores
# 4. Makefile
The makefile must provide 
- make command to build the examples
- clean commands to remove the binary files from the bin directory
- rmlog commands to remove logs from log direcoty

The make commands must reach every file and build in the bin directory. \
All log file must be in the log directory
